# Catatan riset tim

Dokumentasi ini membedakan **hasil terukur**, **keputusan implementasi**, dan **rencana**.
Tujuannya bukan membuat hasil terlihat lebih baik, tetapi membantu pembaca mengulang
pekerjaan kami, memahami keputusan yang berubah, dan mengetahui batas buktinya.

| Dokumen | Pokok pembahasan |
|---|---|
| [Metodologi](METODOLOGI.md) | Representasi tracking, missingness, simetri, model temporal, kalibrasi, decoder |
| [Protokol dan hasil](PROTOKOL_DAN_HASIL.md) | Split per laga, skenario gangguan, tabel hasil dan ablation |
| [Data dan provenance](DATA_DAN_PROVENANCE.md) | Sumber, pembentukan label eksternal, lisensi, batas data target |
| [Reproduksi](REPRODUKSI.md) | Instalasi, inferensi beku, hash, pengujian, pelatihan ulang |
| [Kepatuhan](KEPATUHAN.md) | Pemisahan data, catatan manual, publikasi, dan keterbatasan audit |
| [Referensi](REFERENSI.md) | Sumber primer dan pembagian lisensi |
| [Dokumen teknis singkat](../Hijrah%20ke%20Barcelona.md) | Ringkasan berbahasa Inggris untuk pengumpulan |

Versi awal tetap disimpan sebagai arsip. Teks lama yang menyebut menu 7 sebagai
kandidat utama menggambarkan keputusan pada saat itu, bukan kandidat rilis equal5.
Tidak semua eksperimen di arsip masuk inferensi pengumpulan.
